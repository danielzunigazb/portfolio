1Projects

Real software, not exercises. Every project has code, docs and tests.

1.1Player

Native Android music player, with no accounts and no cloud. Synced lyrics, a terminal with autocomplete, a web monitor you pair by QR code, Android Auto and a widget. Version 1.6.1 stable, with UI, service and database tests, and CI that signs the releases.

Keywords: Kotlin, Jetpack Compose, Media3, Room.

1.2zwm

Tiling window manager for X11, written in Zig. Top bar, a side panel with calendar, music and notifications, a launcher with a calculator, and a lock screen with PAM.

Keywords: Zig, X11, PAM, Spotify Connect.

Status
private

1.3gocraft

Minecraft Java 1.8.9 client and server (protocol 47) in Go. Runs on Linux and Windows, renders with OpenGL 3.3 and includes a PvP mode with 1.8 click rules. It ships no Mojang assets, and its fidelity with vanilla is pinned by tests that replay packets against the client.

Keywords: Go, OpenGL 3.3, GLFW, protocol 47.

Status
active

[4] repository

1.4editor

Non-linear video editor with no interface: an LLM drives it end to end through an MCP server. MLT + FFmpeg engine with cuts, transitions, subtitles and 15 visual templates. Runs as a web app or as an MCP server, dockerized with real hardening and Playwright e2e tests.

Keywords: Python, MCP, MLT, FFmpeg, Docker.

Status
active

1.5harness

Personal development tool: a CLI that orchestrates code agents over real repositories with a verification loop. It plans, executes step by step, verifies with the repo's own tests, repairs and reports. “The model says it's done” doesn't count as evidence.

Keywords: TypeScript, Node.js, Claude Code.

Status
