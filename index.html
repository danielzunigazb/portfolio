Framework mínimo para orquestar scripts Python con servicios systemd user. Proporciona una base Hook class con ciclo de vida setup/run/teardown, paths XDG-compliant, logging estructurado a JSONL con forwarding a journald, y auto-descubrimiento de hooks mediante HookRegistry.

§ 02

Principles

Principios con los que construyo y opero sistemas.

01
Reproducibilidad por defecto
No confío en artefactos binarios sin checksum. No versiono datos, solo manifiestos, scripts y URLs. Todo pipeline debe poder reconstruirse desde cero con un solo comando.
02
Documentación como infraestructura
Un sistema sin documentación es un sistema fallido. ADRs para decisiones de arquitectura, worklogs para trazabilidad, READMEs funcionales. La documentación se mantiene tan rigurosa como el código.
03
Testing no negociable
Si no tiene tests, no está terminado. Cobertura ≥85%, type checking, linting. Los CI gates deben pasar antes de mergear. Las excepciones se documentan y se auditan.
04
Portabilidad vía estándares
XDG Base Directory Specification para paths de configuración y datos. systemd para servicios. Sin hardcodeo de rutas. Todo debe migrar entre máquinas copiando un directorio.
05
Observabilidad desde el inicio
Logs estructurados, health checks, monitoreo continuo. Un sistema debe poder auditarse sin intervención humana. Si algo falla, debe haber evidencia de por qué.
06
Menos but more
Frameworks mínimos, dependencias justas. CLI sobre GUI cuando sea viable. Código simple que hace una cosa bien. Evitar abstracciones prematuras.
