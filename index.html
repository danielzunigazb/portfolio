Software real, no ejercicios. Cada proyecto tiene código, documentación y tests.

1.1Player

Reproductor de música nativo para Android, sin cuentas ni nube. Letras sincronizadas, terminal con autocompletado, monitor web por QR, Android Auto y widget. Versión 1.6.1 estable, con tests de UI, servicio y base de datos, y CI que firma los releases.

Palabras clave: Kotlin, Jetpack Compose, Media3, Room.

1.2zwm

Gestor de ventanas en mosaico para X11, escrito en Zig. Barra superior, panel lateral con calendario, música y notificaciones, lanzador con calculadora y pantalla de bloqueo con PAM.

Palabras clave: Zig, X11, PAM, Spotify Connect.

1.3gocraft

Cliente y servidor de Minecraft Java 1.8.9 (protocolo 47) en Go. Corre en Linux y Windows, renderiza con OpenGL 3.3 e incluye un modo PvP con reglas de clicks de 1.8. No trae recursos de Mojang, y su fidelidad con vanilla está fijada con pruebas que reproducen paquetes contra el cliente.

Palabras clave: Go, OpenGL 3.3, GLFW, protocolo 47.

Estado
activo

1.4editor

Editor de video no lineal sin interfaz: un LLM lo maneja completo vía un servidor MCP. Motor MLT + FFmpeg con cortes, transiciones, subtítulos y 15 plantillas visuales. Corre como app web o como servidor MCP, dockerizado con hardening real y tests e2e con Playwright.

Palabras clave: Python, MCP, MLT, FFmpeg, Docker.

Estado
activo

1.5harness

Herramienta de desarrollo personal: una CLI que orquesta agentes de código sobre repositorios reales con un ciclo de verificación. Planifica, ejecuta paso a paso, verifica con los tests del propio repo, repara y reporta. «El modelo dice que terminó» no cuenta como evidencia.

Palabras clave: TypeScript, Node.js, Claude Code.
